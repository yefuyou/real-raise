# 你的涨薪，消失在到手之前了吗？

## Real Raise

> 把税前工资、个税、社保公积金和生活支出拆开，看清真正到手的变化。

Real Raise 是一个面向中国职场人的个人收入诊断工具。它不只问“工资涨了多少”，而是继续追问：

```text
税前收入
  ↓ 扣除个税、社保、公积金
真正到手
  ↓ 扣除日常生活支出
可支配结余
```

主问题是：**你的涨薪，消失在到手之前了吗？**

## 为什么做它

工资条上的涨幅，不等于银行卡里真正多出来的钱。个税、社保、公积金会改变当月到手现金；食品、交通、医疗、教育和其他日常支出，又会改变最后能留下多少。

Real Raise 把这些变化放进一条可核对的链路里：

> **收入变化 → 扣缴变化 → 到手变化 → 生活成本变化 → 可支配结余变化**

所有核心金额由本地确定性公式计算。模型只负责解释、对比和生成情景，不负责改数字。

## 当前可以体验什么

- 输入当前与下一阶段的到手收入
- 输入可选的住房/固定支出变化
- 输入日常生活支出和预计变化率
- 基础模式与六类日常支出详细模式
- 查看每月、每年可支配结余变化
- 查看“收入增加、固定支出、日常支出、最终结余”的瀑布路径
- 使用预设案例快速体验不同的涨薪结果
- 查看 2021–2025 年收入、消费与 CPI 历史基准
- 使用 2026 年上半年已公布 CPI 作为日常支出估算起点

当前 MVP 的输入是“到手收入”，因此不会假装已经完成税前工资和城市扣缴计算。下一阶段会增加工资条模式：税前工资、个税、养老、医疗、失业、住房公积金和其他扣缴分开输入或按城市规则估算。

住房支出只是一个可选的固定支出项，不再承担产品主叙事。用户也可以把它设为 0，直接观察扣缴和日常支出对结余的影响。

## 城市数据策略

国家统计局“国家数据”提供“主要城市月度价格”和“主要城市年度数据”入口，城市 CPI 可以通过官方数据查询或各地统计局/国家调查队发布页核验：

- [国家统计局：国家数据](https://data.stats.gov.cn/easyquery.htm?cn=E0104)
- [国家统计局：主要城市 CPI 数据查询说明](https://www.stats.gov.cn/hd/lyzx/zxgk/202405/t20240524_1953492.html)
- [国家统计局：2026 年上半年居民消费价格主要数据](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260709_1964084.html)

城市层采用三档口径：

1. 有已核验的城市分类数据时，显示城市基准并标明月份、范围和来源。
2. 只有城市综合 CPI 时，只用于“城市价格背景”，不拆成八类，不伪造细项。
3. 城市数据缺失时回退到全国/城镇基准，并在页面明确提示。

住房支出永远优先使用用户自己输入的金额；城市房价或城市 CPI 不会被当作个人住房支出预测。

## 数据与模型原则

### 数字由确定性公式负责

核心计算位于 [`src/domain/livingCost.ts`](./src/domain/livingCost.ts)。平台返回的文字不能覆盖本地数字。

### 官方值、派生值、用户输入分开

- `verified`：来自国家统计局或地方统计部门的已核验原值。
- `derived`：根据官方分类数据和用户消费结构派生的估算。
- `user-input`：用户自己的工资、扣缴、住房和生活支出。
- `forecast`：情景预测，必须显式标注假设，不能写成官方数据。

### 2026 CPI 的使用边界

截至 2026 年 7 月 26 日，国家统计局已公布到 6 月，1—6 月全国 CPI 同比上涨 1.0%。项目把 2026H1 八类 CPI 作为观察基准，而不是全年或下一年度官方预测；用户可以手动修改下一阶段支出变化率。

## InfiniSynapse 在项目中的作用

InfiniSynapse 是解释层，不是计算器：

- 读取已启用的公开收入、消费和 CPI 数据源。
- 解释用户的结果为什么上升或下降。
- 将用户结构与全国、城镇或城市基准对比。
- 给出带来源的情景说明。

浏览器只请求本项目后端，API Key 不进入前端。默认本地模式不消耗平台额度。

## 安全边界

不会提交以下内容：

- InfiniSynapse API Key 或任何 Secret
- `.env` 文件
- 用户工资条、银行流水和个人扣缴明细
- 未脱敏的任务日志
- 没有来源、年份和统计范围的数字
