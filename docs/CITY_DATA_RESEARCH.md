# 城市数据研究结论

更新时间：2026-07-26

> **执行优先级调整：合肥（340100）为第一城市样本。** 用户所在城市先做可核验数据闭环，再扩展其他城市；没有官方分类值的年份不做插值或城市替代。

## 结论

**城市数据支持，而且足以做第一版城市基准。** 但“支持”不是每个城市每个月都拥有完整、同口径的八类数据，因此产品必须显示覆盖范围和回退层级。

截至 2026-07-26，已完成当前期完整分类核验的城市包括：北京、深圳；上海已完成当前期综合 CPI 与月度八类样本；合肥已完成 2024 年完整历史分类样本，2026H1 仍按类别回退全国基准。

## 已确认的官方入口

### 国家统计局国家数据

国家数据的地区数据菜单包含：

- 分省月度数据
- 分省季度数据
- 分省年度数据
- 主要城市月度价格
- 主要城市年度数据

国家统计局公开答复也说明，主要城市 CPI 可以在“国家数据 → 地区数据 → 主要城市月度价格”中设定指标和时间，注册后下载：[国家数据主要城市月度价格](https://data.stats.gov.cn/easyquery.htm?cn=E0104)。

### 地方统计局/调查队发布

- [北京：2026 年 6 月 CPI](https://tjj.beijing.gov.cn/zxfbu/202607/t20260710_4755986.html)：披露北京当月 CPI、食品、非食品、消费品和服务价格同比/环比，并解释具体价格变化。
- [上海：2026 年 6 月 CPI 新闻稿](https://tjj.sh.gov.cn/sjxx/20260710/44c96140acff4d889c7dc1cb5f13d4f0.html)：披露上海当月 CPI 与八大类同比/环比，以及 1—6 月平均 CPI。
- [上海：2026 年 6 月居民消费价格表](https://tjj.sh.gov.cn/ydsj61/20260710/7e23d8d669d1456189e8e966b3f9f277.html)：页面提供可下载的官方 XLS，适合清洗成结构化城市数据。
- [深圳：2026 年 6 月国民经济核算资料](https://tjj.sz.gov.cn/attachment/1/1216/1216381/10010079.pdf)：列出深圳 CPI 和八大类 6 月、1—6 月指数，来源标注为国家统计局深圳调查队。
- [广州统计年鉴 2025：2024 年全国 36 个大中城市 CPI 表](https://tjj.gz.gov.cn/datav/admin/home/www_nj/2025/pdfs/7-8%20%20%E5%85%A8%E5%9B%BD36%E5%A4%A7%E4%B8%AD%E5%9F%8E%E5%B8%82%E5%B1%85%E6%B0%91%E6%B6%88%E8%B4%B9%E4%BB%B7%E6%A0%BC%E6%8C%87%E6%95%B0%28%E4%B8%8A%E5%B9%B4%3D100%EF%BC%8C2024%E5%B9%B4%29.pdf)：公开列出合肥市 2024 年综合 CPI 与八类 CPI，可作为合肥第一版完整分类样本。

| 食品烟酒 | 102.4 | +2.4% |
| 衣着 | 100.8 | +0.8% |
| 居住 | 100.6 | +0.6% |
| 生活用品及服务 | 101.5 | +1.5% |
| 交通通信 | 106.8 | +6.8% |
| 教育文化娱乐 | 103.6 | +3.6% |
| 医疗保健 | 100.1 | +0.1% |

## 可直接使用的上海 2026H1 样本

上海官方新闻稿披露 1—6 月 CPI 同比上涨 0.8%，6 月同比上涨 1.0%；6 月八大类同比包括：食品烟酒及在外餐饮 -0.6%、衣着 +1.4%、居住 +0.4%、生活用品及服务 +2.1%、交通通信 +3.8%、教育文化娱乐 +3.1%、医疗保健 -1.2%、其他用品及服务 +7.7%。完整表格可从官方 XLS 下载。

## 合肥优先样本

合肥使用 `cityCode = 340100`。第一版先采用 2024 年完整分类数据，避免把省级数据或第三方预测值冒充合肥数据：

| 类别 | 2024 年指数（上年=100） | 同比涨幅 |
| --- | ---: | ---: |
| 居民消费价格总指数 | 100.4 | +0.4% |
| 食品烟酒 | 100.6 | +0.6% |
| 衣着 | 101.8 | +1.8% |
| 居住（宏观参照） | 100.3 | +0.3% |
| 生活用品及服务 | 99.9 | -0.1% |
| 交通通信 | 97.9 | -2.1% |
| 教育文化娱乐 | 101.0 | +1.0% |
| 医疗保健 | 101.4 | +1.4% |
| 其他用品及服务 | 103.9 | +3.9% |

数据来自官方年鉴表，当前可标为 `A-history`：有完整八类，但期间是 2024 年，不应在界面上伪装成 2026H1。合肥 2026 年最新综合 CPI 和分类值继续从国家数据“主要城市月度价格”及合肥/安徽调查队公告核验；在核验完成前，2026H1 计算回退到全国基准，页面显示“合肥分类数据待更新”。

合肥 2024 年统计公报还提供了居民收入与消费背景：城镇居民人均可支配收入 62685 元、城镇居民人均消费支出 36135 元；这类年度背景只能用于参考对照，不替代用户自己的工资条和支出输入。

## 产品如何使用城市数据

### 现阶段

先不做全国所有城市的实时抓取。建立以下数据契约：

```ts
type CityCpiRow = {
  cityCode: string
  cityName: string
  period: string       // 例如 2026H1 或 202606
  category: string     // overall / food / housing / ...
  indexBase: string    // yoy=100 或 mom=100
  value: number
  sourceUrl: string
  sourceName: string
  coverage: 'city-category' | 'city-overall' | 'fallback'
}
```

### 页面规则

1. 用户选择城市后，优先读取该城市、该期间、该类别的已核验数据。
2. 城市只有综合 CPI 时，只显示“城市综合价格背景”，不拆成八类。
3. 城市缺少某个类别时，该类别回退全国/城镇基准，并显示回退提示。
4. 住房/固定支出仍以用户输入为准；城市“居住”数据不代替用户真实支出。
5. 城市平均收入和消费支出只做参考，不把它当作用户工资或消费结构。

## 推荐的首批城市

首批不只做 3 个城市，扩展为 30 城：北京、上海、广州、深圳、天津、重庆、成都、杭州、南京、武汉、西安、苏州、宁波、青岛、济南、郑州、长沙、合肥、福州、厦门、昆明、贵阳、南宁、海口、石家庄、太原、沈阳、大连、长春、哈尔滨。

合肥先作为第一优先样本：先接入 2024 年完整分类数据，并追踪 2026 年官方更新；上海和深圳作为当前 2026H1 分类样本。北京、广州、杭州、成都、武汉、南京、重庆、西安、苏州、天津按官方国家数据或本地统计局页面逐城核验。每个城市可以处于不同覆盖档，不要求所有城市都硬凑完整八类。

这批城市的价值在于覆盖一线、新一线、东部、中部、西部、东北和不同消费结构；它们不是对所有中国城市的统计代表性承诺。数据清洗按三批十城推进，不要求一次性补齐全部分类字段。

## 不做的事

- 不用 70 城商品住宅价格指数代替城市生活成本。
- 不用城市平均房租推算个人住房支出。
- 不用搜索摘要直接写入正式数据；正式数据必须下载或打开官方原表核对。
- 不把深圳或上海样本外推成全国城市结论。
