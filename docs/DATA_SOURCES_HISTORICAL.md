# 2021–2025 年国家统计局历史公开数据档案 (Historical Data Record)

> [!NOTE]
> 本文档登记 2021 至 2025 年间由国家统计局发布的居民收入、中位数、城乡消费总额、全国及城镇八大类消费支出与 CPI 同比数据。

## 数据来源三分法架构 (Three-Tier Data Architecture)

根据项目契约与严格统计真实性原则，本架构中的所有字段明确划分为以下三种来源类型：

1. **已核验官方原值 (verified)**：
   - 严格来自于国家统计局官方新闻发布稿或《中国统计年鉴》表 2 的公开数据。
   - 包含：2021–2025 年全国/城镇/农村人均可支配收入、收入中位数、消费支出总额；全国八大类消费支出金额；2021–2023 及 2025 年城镇八大类消费支出金额；全国总体及八大类 CPI 年同比。
   - 特别标记：2024 年城镇八大类因未在发布稿或 Excel 中单列核验，已直接从官方原值表中剔除，不以未核验数据滥充官方原值。
2. **派生估算值 (derived)**：
   - 基于 `verified` 官方八大类 CPI 同比数据与 2025 年城镇居民消费结构按加权公式派生的“非房租其他支出变化率”（如 `deriveNonRentInflationRate()`）。
   - 仅用于提供确定性的宏观基准参考，不作为国家统计局直接发布的指数。
3. **用户实际输入值 (user-input)**：
   - 用户在前端输入的“当前月收入”、“预计月收入”、“当前月房租”、“预计月房租”及“其他月支出”。
   - 具有最高优先级，绝对不被官方 CPI 居住类或派生值覆盖。

## 质量控制与规则约束

1. **官方准确性**：所有已整理的数值均与规范的 Canonical 官方页面完成全量对齐。
2. **零猜测与零伪造**：缺失项（如 2025 年农村中位数）显式为 `null`；未核验项（2024 城镇八类）直接删除。
3. **公式解耦**：无任何文件改动 `src/domain/livingCost.ts`，未修改 UI 布局，不涉及 InfiniSynapse 接口调用。
4. **分类求和校验**：八类官方支出保留官方表格原值；由于发布表格为四舍五入后的元值，分类求和与官方总额允许出现不超过 1 元的舍入差异。2024 年城镇八类明细暂不进入已验证数据。
