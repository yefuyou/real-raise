# Real Raise 项目总策划与分工

更新时间：2026-07-25

## 一句话目标

让中国城市租房上班族在 30 秒内回答：**我的工资上涨之后，扣掉房租和生活成本，我到底有没有变得更宽裕？**

## 交付优先级

### P0：必须能演示

- 用户输入当前/明年收入、房租、其他月支出
- 确定性计算真实购买力与结余变化
- 结果能解释“涨薪被什么吃掉了”
- 三个一键演示案例
- 手机端可用

### P1：让作品可信

- 中国公开统计数据的本地化数据包
- 当前第一版数据包：2021–2025 全国 CPI 八大类、居民消费结构、城乡收入与消费基准
- 每个数据字段的来源、年份、统计范围和单位
- “真实房租优先，居住类 CPI 只做参考”的口径说明
- 公式测试与边界输入处理
- 分析展示按 [`ANALYSIS_DIMENSIONS.md`](./ANALYSIS_DIMENSIONS.md) 执行，不扩成泛数据大屏

### P2：接入平台

- [ ] 从 `officialHistorical.ts` 导出三份干净上传文件：收入消费总额、CPI 年度数据、八类消费支出。
- [ ] 准备 `data_dictionary.md`：字段、单位、年份、统计范围、来源 URL、2024 城镇八类缺失说明、2022 年舍入差异说明。
- [ ] 在 InfiniSynapse 控制台创建一个公共基准数据源并上传上述文件；不上传个人工资、房租或银行流水。
- [ ] 创建并绑定一个知识库，上传字段说明和产品口径；启用数据源后再创建任务。
- [ ] 服务端调用 InfiniSynapse，API Key 只放服务端环境变量。
- [ ] 服务端先接 SSE，再发送 `newTask`，并把供应商事件映射为本项目的任务状态。
- [ ] AI 只做数据解释、对比和情景文案；数字由本地计算器提供，模型不得重算或修改。
- [ ] 前端只调用本项目后端，不直接调用 InfiniSynapse。
- [ ] 缓存同一输入，开发期最多用 2–3 次真实任务；远程功能默认关闭。
- [ ] 完成一次真实闭环：输入 → 本地计算 → 后端任务 → SSE 进度 → AI 解读 → 来源展示。
- [ ] 真实闭环完成后再录制比赛 Demo，不把 Mock 状态误称为真实接口。

### P3：部署与提交

- [ ] 前端部署到 Vercel / Netlify / Cloudflare Pages 之一，直接使用平台提供的临时公网子域名，不购买自有域名。
- [ ] 后端部署为同平台 Serverless/Worker；如果 SSE 长连接不稳定，改用 Render/Railway 的 Node 服务托管后端。
- [ ] 在托管平台配置 InfiniSynapse API Key 等服务端 Secret，禁止进入前端构建产物。
- [ ] 配置生产环境前端地址、后端地址和远程 feature flag。
- [ ] 用公网地址完成一次真实任务：页面可打开、能提交、能看到进度、能得到结果。
- [ ] 检查手机端、异常/超时、API Key 缺失和额度耗尽时的降级页面。
- [ ] 整理提交材料：应用简介、公网 URL、InfiniSynapse 集成说明、代码仓库（可选）。
- [ ] 公共体验默认使用预设案例/本地 Mock，不消耗项目方额度。
- [ ] 增加“使用我的 InfiniSynapse 账号真实分析”入口，优先接 InfiniSynapse 登录授权；备选为用户输入自己的 API Key。
- [ ] BYOK 模式只在服务端通过 HTTPS 使用密钥：不写入前端、不进 URL、不进日志、不落盘，任务结束或短 TTL 后销毁。
- [ ] 未提供用户授权/Key 时，禁止偷偷回退到项目方 API Key；只能使用 Mock 体验。
- [ ] 对 BYOK 任务设置单任务限制、超时、取消和额度提示，避免误用用户自己的额度。

## 数据与计算原则

1. 用户输入的真实房租优先于任何宏观 CPI 代理值。
2. 不把全国“居住”类价格变化说成用户实际房租变化。
3. 个人生活成本涨幅必须说明是“用户权重下的估算”。
4. 所有展示数字由本地确定性函数计算。
5. AI 不能修改数字，只能解释已给出的结果。
6. 没有来源、年份、统计范围的数字不进入正式结果页。

第一版数据口径和来源记录见 [`DATA_SOURCES_2025.md`](./DATA_SOURCES_2025.md)；历史数据接入后补充 [`DATA_SOURCES_HISTORICAL.md`](./DATA_SOURCES_HISTORICAL.md)。
