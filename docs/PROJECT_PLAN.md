# Real Raise 项目总策划与分工

更新时间：2026-07-26

## 一句话定位

**你的涨薪，消失在到手之前了吗？**

把税前工资、个税、社保、公积金和日常生活支出串起来，回答“涨薪之后真正多了多少可支配现金”。

## 产品边界

当前 MVP 先使用“到手收入”输入，保证公式可验证；住房支出是可选固定支出，不再作为主线。下一阶段新增工资条模式：

```text
税前工资 → 个税/社保/公积金 → 到手工资 → 日常支出 → 可支配结余
```

城市数据只做有来源的基准对比，不把城市 CPI、房价或平均工资直接当作个人预测。

## 交付优先级

### P0：必须能演示

- 新标题和新叙事完整替换旧的房租中心文案。
- 到手收入、可选住房/固定支出、日常支出可以本地计算。
- 显示收入增加、扣除/固定支出、日常支出和结余变化的瀑布路径。
- 三个案例：到手缩水、固定支出分走增长、涨薪真正变轻松。
- 手机端可用，加载/失败/取消状态明确。

### P1：让数据可信

- 2021–2025 官方历史收入、消费和 CPI。
- 2026H1 官方八类 CPI 观察基准。
- 首批 30 城城市数据三档回退：城市分类、城市综合、全国/城镇基准。
- 每个数据字段带年份、范围、单位、来源和数据层级。
- 预测与官方已公布值严格分开。

### P2：税前工资与城市层

- 增加税前工资、个税、养老、医疗、失业、公积金输入。
- 先支持“用户填写工资条扣缴额”，再做城市规则估算。
- 建立城市数据契约：`cityCode / period / category / value / scope / sourceUrl`。
- 优先接入官方可下载的主要城市月度价格和年度数据；缺失则回退并提示。
- 不硬编码全国统一社保比例；城市基数和缴费规则必须有有效期与来源。

### P3：平台与发布

- 本地先算，InfiniSynapse 只解释。
- 服务端保存 API Key，前端不直连平台。
- 远程任务必须有 feature flag、缓存、超时、取消和额度提示。
- 使用 Vercel/Netlify/Cloudflare Pages 等临时公网域名，不要求购买域名。
- 公开体验默认 Mock 或预设案例，不消耗项目方额度。

## 当前验收标准

- 页面主标题为“你的涨薪，消失在到手之前了吗？”。
- 页面不再以任何单一住房支出作为主结论。
- 住房支出可选，设为 0 时产品仍然完整可用。
- 2026H1 默认基准有明确“已公布观察值”标识。
- 城市数据缺失时不阻塞计算，页面显示回退说明。
- `npm run verify`、`npm run build` 和本地测试通过。
