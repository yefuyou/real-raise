## 〇、按方法论先过三道检查（不合格就不配写开头）

**1. 内容质量自检（dbs-hook Phase 2：素材清单）**

| 素材类型 | 我们有什么 | 达标 |
| --- | --- | --- |
| 晒结果 | 结果页截图：税前 +1000 → 到手 +751 → 月结余变化 | ✅ |
| 数据 | 国家统计局 2026H1 CPI、个税/社保扣缴拆解 | ✅ |
| 反差 | 涨薪 1000 ≠ 多 1000；"恭喜涨薪"和"月底没多"同框 | ✅ |
| 金句 | "先算清楚，再决定要不要庆祝""AI 只解释，不改数" | ✅ |
| 痛点 | 发工资那天很爽，月底对账单沉默 | ✅ |
| 权威 | 每个数字带国家统计局来源链接 | ✅ |

素材达标，可以写开头。

**2. 单一核心（dbs-resonate 铁律："说了六件事等于什么都没说"）**

- **主视频（抖音/视频号/微博）核心只有一句**：你的涨薪在到手之前就缩水了——花 30 秒算清它去哪了。
- ❌ 主视频里**不讲**：AI 架构、数据四分法、城市回退、评委叙事、比赛细节。那些是评委和技术圈的语言，放 B 站版。
- **B 站技术版核心**："AI 不许改数字"——一个反常识的架构决定。

**3. 传播心理定位（dbs-spread 五理论，直接决定文案立场）**

- 沉默的螺旋：替观众说出憋着的话——"工资涨了但生活没变好，说出来怕显得不知足"。视频就是那句"你没错，账真的是这么算的"。
- 使用与满足：转发满足两件事——吐槽宣泄 + 社交货币（"我算过这笔账"显得清醒）。
- 框架：全程站打工人立场。不站公司、不站专家、不教育观众"你该感恩"。
- 两级传播：第一批转发者是刚涨薪没感觉的人、常发工资条吐槽的人、职场博主。结尾给他们一句现成的转发语。
- 认知一致性：确认"我早就觉得涨薪没用"的直觉，然后给一个 30 秒的低成本行动。

## 一、15 条候选开头（dbs-hook：前 5 秒独立工作，口播友好）

**素材提取法（晒结果 > 数据 > 反差 > 金句 > 权威 > 痛点）**

1. 涨薪一千，到手七百五。剩下二百五去哪了？我算给你看。
2. 我把这次涨薪拆开算了一遍，结果有点难看。
3. 税前涨一千，个税社保先拿走二百四十九。这还没完。
4. 恭喜你涨薪。也提前节哀——有一截根本到不了你手里。
5. 工资条上的涨幅，和银行卡里的涨幅，是两个数。
6. "先算清楚，再决定要不要庆祝。"这是我今年听过最扎心的话。
7. 发工资那天你很开心，月底对账单让你闭嘴。问题出在哪？
8. 你的涨薪，消失在到手之前了吗？

**悬念制造法（留问题，不给答案）**

9. 你知道自己上次涨薪，真正落袋多少吗？大部分人不知道。
10. 涨薪之后钱去哪了？三个去向，最后一个最隐蔽。
11. 为什么涨了薪，月底反而更紧？这不是错觉。
12. 有个数字叫"真实涨薪率"，九成打工人没算过。

**反常识结论法**

13. 涨薪不等于加钱。这句话我说给每个刚调薪的人听。
14. 你以为的涨薪是加法，实际上是减法做完之后剩下的。
15. 越是涨薪的时候，越要算账——因为扣的也跟着涨了。

> 推荐主用 **1**（晒结果+数据+悬念三合一），备选 **9**（纯悬念）和 **4**（反差最强）。同一脚本换开头可以做 AB 测试发两个账号。

## 二、主视频完整脚本（竖屏口播 + 录屏，55 秒）

> 口播每句 ≤ 30 字（dbs-script-flow 要求）；【】内是画面。字幕全程。

| 时间 | 口播 | 画面 |
| --- | --- | --- |
| 0–5s | 涨薪一千，到手七百五。剩下二百五去哪了？我算给你看。 | 【真人出镜或大字动画："+1000 → +751"，红色划掉 249】 |
| 5–12s | 这是个免费小工具，叫"真实涨薪"。填上工资条，它帮你把账拆开。 | 【录屏：打开页面，切到工资条模式，填示例数字】 |
| 12–22s | 第一刀，个税。第二刀，社保公积金。别骂，养老和公积金是进了你的未来账户，不算丢。 | 【录屏：瀑布图逐项出现：−个税、−社保公积金；字幕标"未来账户 ≠ 消失"】 |
| 22–32s | 第三刀最隐蔽：物价。它用国家统计局刚公布的 CPI，算你日常开销要多花多少。 | 【录屏：日常支出变化 + 来源抽屉里"国家统计局"字样特写】 |
| 32–42s | 三刀下来，屏幕上这个数，才是你真正的涨薪。比工资条上的小多少，每个人不一样。 | 【录屏：月结余变化大数字特写，停 2 秒】 |
| 42–50s | 数字全是本地公式算的，AI 只负责解释，不许改数。每个数都有官方来源，你可以点开验。 | 【录屏：AI 解读卡 + 点开来源链接】 |
| 50–55s | 链接在评论区。算完欢迎回来报数：你的涨薪，实际到手几成？ | 【定格结果页 + 字幕："你的涨薪，消失在到手之前了吗"】 |

**结尾 CTA 设计说明**："回来报数"是互动钩子——评论区晒"到手几成"会滚起 UGC，比"求赞"有效。比赛拉票放在**置顶评论**：体验链接 + 投票链接 + 一句"顺手投一票"。抖音/视频号正文别放外链，会限流。

**封面标题（三选一，可配"工资条"实拍图）**

- 涨薪 1000，到手 751
- 你的涨薪，消失在到手之前了吗
- 打工人都该算一次的账

## 三、B 站技术版骨架（横屏，2–3 分钟）

核心："AI 不许改数字"。观众：技术人/CSDN 人群，也是投票主力。

1. **开头（15s）**：做 AI 数据应用最容易翻车的地方，是让大模型算数——算错了没人发现。我们反着来：AI 一个数字都不许碰。
2. **产品演示（40s）**：工资条 → 确定性瀑布 → 结余。强调"这些数字全部来自本地公式，测试盯着，改一行就爆红"。
3. **架构讲解（60s）**：浏览器→自有后端→InfiniSynapse Server API；SSE 任务流；AI 只读官方数据源做带来源的解释；产物 evidence.csv 可下载核验；同输入缓存不重复扣额度。
4. **数据诚实（20s）**：官方值/派生值/用户输入分级标注；城市数据缺了就明说回退，不编数。2025 农村中位数官方没公布，我们就写"未单独公布"。
5. **结尾（15s）**：这是我们参加 InfiniSynapse×CSDN Vibe Coding 大赛的作品，链接和投票入口在简介和置顶。你觉得"AI 只解释不改数"这条边界划得对吗？评论区聊。

## 四、拍摄与剪辑执行清单

**录屏素材（拍之前把这几段先录好，1080×1920 竖屏浏览器窗口）**

1. 首页大标题进场（3s）
2. 切换到工资条模式 + 填入示例（8s）⚠️ 依赖工资条模式上线——落盘后我第一个做的就是它
3. 瀑布图逐项展开（8s）
4. 城市 CPI 卡 + 来源抽屉点开国家统计局链接（6s）
5. 月结余大数字特写（4s）
6. AI 解读进度条 → 完成 → 产物下载（8s，提前跑一次命中缓存，避免录到转圈）

**剪辑要点**：字幕全程大字号；关键数字用动画放大（+1000 → −83 → −166 → +751）；BGM 选轻快不抢词的；口播语速 4.5–5 字/秒，55 秒 ≈ 260 字，上面脚本正好。

**发布节奏**：主视频发抖音/视频号/微博（微博配文用文案包第 1 条，@祝威廉二世）；B 站版第二天发；两条都把投票链接放置顶评论。

**依赖提醒**：脚本里的"税前 1000 → 到手 751"来自工资条示例数据，发布前确认工资条模式已上线且示例数字一致；如果先发预告期视频，改用第 9 条纯悬念开头 + 现有到手模式录屏。
