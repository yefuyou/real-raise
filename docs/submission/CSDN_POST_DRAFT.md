## 一个反常识的设计决定：AI 不许碰数字

做 AI 数据应用最容易翻的车，是让大模型算数——算错了没人发现，发现了没法解释。我们反着来：

- **所有金额由本地确定性公式计算**，公式在 `src/domain/` 里，10 项自动化断言盯着，改一行就爆红；
- **InfiniSynapse 只做解释层**：读取已启用的国家统计局公开数据源，解释"你的结余为什么变多/变少"、和全国基准差在哪，输出每一条引用都带年份和统计范围；
- prompt 里写死硬边界：不得重算或修改本地数字，城市缺数必须明说"已回退全国基准"。

AI 擅长的是跨来源解释，不是算个税。把两件事分开，数字可验证，解释有来源。

## 数据诚实是产品功能，不是免责声明

- 每个数字分四类标注：**官方核验原值 / 派生估算 / 用户输入 / 情景预测**，来源可点击；
- 已核验 2021–2025 官方历史基准、2026H1 全国八类 CPI，以及北京、上海、深圳、合肥的城市样本；
- 城市分类数据缺失时，页面直接说"该城市当前分类数据暂缺，已使用全国基准"——不插值、不拿省数据冒充城市数据；
- 2025 年农村收入中位数官方没单独公布，我们就显示"未单独公布"，而不是编一个。

## InfiniSynapse 集成：我们连服务器都没有

```text
你的浏览器 ──(你自己的 Key)──▶ InfiniSynapse Server API
     │            ↑ SSE 进度 · Task Workspace 产物
     └── 没填 Key？看真实任务存档回放（任务 ID 可在平台后台核验）
```

- 纯静态站 + BYOK：Key 只写进**你自己浏览器**的 localStorage，本应用没有任何服务器，不经手、不存储任何人的 Key——打开浏览器网络面板即可验证请求只发往 app.infinisynapse.cn；
- 前端先建 SSE 连接再下发任务，事件归一化成进度流；任务完成读取 Task Workspace 取回三份产物：`explanation.md`（解释）、`evidence.csv`（证据行）、`analysis-manifest.json`（口径清单），可预览可下载；
- 不填 Key 也能看到真实集成：内置真实任务的**存档回放**，附任务 ID，评委和读者都能去平台后台核验；
- 同输入哈希缓存 + 进行中去重：刷新、双击不会重复扣你的额度；
- 官方统计数据以**数据源 + 知识库**登记在演示账号（绑定数据口径字典），BYOK 实时任务则用内联来源索引，保证任意账号可复现。
