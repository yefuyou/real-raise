# Antigravity / 哈吉米执行清单

项目：**涨薪还剩多少？**

本清单面向哈吉米（Antigravity，Gemini 模型）的重复性执行工作。所有任务都必须基于已提供的文件或明确指定的资料执行；不自行编造数据、口径、来源或 URL。

## 1. 整理数据源登记表

- 输入：项目负责人提供的官方数据源文件、来源说明或明确的来源清单。
- 输出：按 `src/data/dataContract.ts` 中的数据契约整理后的待填记录；保留无法确认的字段为空并标注待确认。
- 验收标准：每条记录都能追溯到输入资料；`sourceName`、`sourceUrl`、`year`、`scope`、`unit`、`field`、`category`、`value` 不得凭空补写；未提供的 URL 保持为空。

## 2. 执行字段与格式检查

- 输入：已整理的数据源登记表，以及 `src/data/dataContract.ts` 的类型定义。
- 输出：一份字段检查结果，列出缺失字段、类型不匹配、年份格式错误和重复记录。
- 验收标准：检查结果明确区分“通过”和“待修复”；不修改原始数据值；不新增未经证实的内容。

## 3. 生成本地分析数据文件

- 输入：通过字段检查的数据源登记表；项目负责人指定的目标字段和分类。
- 输出：供本地计算使用的结构化数据文件或 TypeScript 数据模块，并附字段映射说明。
- 验收标准：只包含输入资料中存在的记录；字段名与数据契约一致；空值、单位和统计范围均有明确保留；不包含真实个人敏感信息。

## 4. 执行计算结果回归核对

- 输入：项目现有计算逻辑、测试案例和第 3 项生成的数据文件。
- 输出：计算核对表，记录每个案例的输入、预期结果、实际结果和差异。
- 验收标准：金额、百分比、年度换算和保本收入等结果与既定公式一致；发现差异时只记录问题并回传，不擅自修改业务公式。

## 5. 整理前端接入交接包

- 输入：通过核对的数据结构、字段映射说明、计算核对表和项目负责人确定的展示字段。
- 输出：前端可直接使用的字段清单、示例数据形状和待确认问题清单，交给前端执行位（哈吉米）。
- 验收标准：交接包不包含未确认的数据或 URL；每个展示字段都有来源或“本地计算”标记；待确认问题不超过实际发现的问题；前端无需猜测字段含义即可接入。

## 统一禁止事项

- 禁止调用 InfiniSynapse，包括网页端对话、API、任务创建和数据上传。
- 禁止编造真实数据、统计结论、来源名称、来源 URL 或数据口径。
- 禁止修改 `App.tsx`、`styles.css`、`livingCost.ts`、`package.json`。
- 禁止为了验证而消耗平台积分；只能进行本地、可复现的检查。
