# 数据资产目录

> 状态：现行目录
> 最后核验：2026-07-30
> 原则：本页登记“有什么、来自哪里、能做什么”，不把研究计划写成已完成数据。

## 1. 数据分层

| 层级 | 定义 | 优先级 |
| --- | --- | --- |
| `user-input` | 用户实际工资、扣缴、住房和日常支出 | 最高 |
| `verified` | 官方页面、表格或发布稿中的核验原值 | 宏观参照 |
| `derived` | 使用已核验数据和公开公式派生 | 默认估算，必须标注 |
| `fallback` | 目标城市缺失时使用全国基准 | 必须显示回退 |
| `historical` | 城市或全国的历史期原值 | 只作历史背景 |

## 6. 数据更新完成定义

新增或更新一条数据必须同时提供：

1. 官方 URL 或原始可下载文件；
2. 城市/范围、期间、单位和指数口径；
3. `verified` / `derived` / `historical` / `fallback` 分类；
4. 缺失项和回退行为；
5. 结构化文件与来源抽屉映射；
6. 自动化或人工核验记录；
7. Changelog 和 Checkpoint 更新。

## 7. 明确不是数据资产的内容

- 搜索摘要；
- 第三方预测；
- 未核验的城市平均房租；
- 30 城目录本身；
- 用户工资条或银行流水；
- Replay 中的模型叙述性结论；
- 旧文档里写着“下一步补齐”的计划。
