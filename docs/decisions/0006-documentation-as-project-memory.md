# ADR-0006：文档作为项目记忆系统

> 状态：已接受
> 决策日期：2026-07-30

## 背景

项目在高频迭代中积累了多份计划、交接、历史方案和营销稿，但没有现行入口、状态字段、ADR 或 Checkpoint。接手任务时经常从旧文档恢复已废弃路线。

## 决定

- 以 `docs/README.md` 作为唯一入口。
- 产品规格、状态机、ADR、Changelog、Checkpoint、数据目录和 Runbook 分工。
- 旧文件保留原路径，但统一登记为现行参考或历史资料。
- 每次产品路径、认证、契约、数据、合并或部署变化必须更新对应文档。
- 开发前按治理规则完成文档预读。

## 后果

文档维护成为完成定义的一部分。只改代码不更新状态机或 Changelog，不能称为完成。
