# ADR-0003：版本化回放与供应商原件分层

> 状态：已接受
> 决策日期：2026-07-29

## 背景

历史任务使用旧购买力公式且没有城市上下文。仅修改静态包里的当前请求会让旧正文、旧证据和新数字看起来属于同一次分析。

## 决定

- 回放包保存录制请求与当前匹配请求。
- 供应商原件保持不可改写，并保存完整性信息。
- 当前确定性凭证由 Real Raise 按当前公式生成。
- UI 显示 Task ID、录制时间、旧口径和当前口径。
- 包装 schema 与 Prompt 录制版本分开记录。

## 当前差距

现有四个包已升级为 `replay.v2`，但任务仍录制于 2026-07-26 的旧计算口径，且没有 Prompt 版本。修改预设输入会破坏精确签名匹配，因此预设更新与新回放录制必须原子发布。
