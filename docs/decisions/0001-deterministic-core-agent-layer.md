# ADR-0001：确定性计算内核 + Agent 分析层

> 状态：已接受
> 决策日期：2026-07-26
> 最后核验：2026-07-30

## 背景

工资、扣缴、支出和结余需要金额级可复算；模型适合处理开放性的排序、比较、敏感性判断和表达。

## 决定

- Real Raise 生成所有金额、驱动因素和情景矩阵。
- Worker 不信任客户端金额，使用受控输入重新计算。
- Agent 不重新计算或覆盖金额。
- 平台正文与 Real Raise 确定性凭证分层。

## 后果

- 数字更可靠，但平台价值必须通过诊断流程和产物体现，而不是让模型“算钱”。
- Prompt、上下文、计算和产物都必须版本化。
- UI 必须说明数字权威与正文来源。
