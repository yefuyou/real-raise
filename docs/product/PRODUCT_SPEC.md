> 关联：[状态机](./STATE_MACHINES.md) · [决策记录](../decisions/README.md) · [最新 Checkpoint](../checkpoints/2026-07-30-baseline.md)

## 1. 产品定义

### 一句话

帮助中国职场人判断：税前或到手收入变化经过扣缴、住房和日常支出后，真正增加了多少可支配结余。

### 核心架构

```text
用户输入
  → Real Raise 确定性计算
  → 可核验的诊断包与情景矩阵
  → InfiniSynapse Agent 排序、比较、解释
  → 带来源、版本和执行证明的报告
```

### 目标用户

- 正在评估加薪、晋升或跳槽的人。
- 想从工资条理解税前涨幅为何没有等额到手的人。
- 想比较住房和日常支出变化对涨薪留存影响的人。
- 评审或访客：无需登录即可核验真实历史任务，但不能消耗项目方额度。

## 2. 产品原则

1. 金额由确定性公式负责，Agent 不重算金额。
2. 用户实际输入高于宏观平均值。
3. 官方观察值、派生值、用户输入和历史回放必须分层。
4. 登录、回放和报告状态必须与真实执行链一致。
5. 生产 URL 保持为 `https://plain-wind-ae46.yefuyou2333.workers.dev/`。
6. 产品不提供 BYOK，不要求用户把 API Key 放进浏览器。
7. 目标产品不提供 Judge 项目 Key 模式；实时分析只走 Partner SSO 用户归因。

## 3. 核心用户路径

### RR-CALC-001：免登录确定性算表

用户无需登录即可：

- 使用到手收入模式或工资条模式；
- 输入当前与下一阶段收入；
- 输入住房和日常支出；
- 查看月度/年度结余变化、驱动因素和保本收入；
- 查看官方数据来源和城市回退说明。

本地计算不得因 Worker、SSO 或平台异常失效。

### RR-INPUT-001：到手收入模式

- 直接输入当前和下一阶段到手收入。
- 预设案例必须有明确故事和设计目标。
- 预设只修改到手模式数据，不得悄悄切换其他输入模式。

### RR-INPUT-002：工资条模式

- 支持税前、个税、养老、医疗、失业、公积金和其他扣缴。
- 估算值必须标记为估算，允许用户覆盖。
- 工资条模式使用自己的预设，不复用会强制切换到手模式的预设。
- 养老和公积金单独解释为未来保障或账户积累，不笼统称为“消失”。

### RR-AUTH-001：Partner SSO

- 未登录用户可主动登录 InfiniSynapse。
- 登录必须回到发起登录的允许 Origin；本地发起则回本地，生产发起则回生产。
- 浏览器不得获得 Partner API Key。
- 登录用户的实时任务必须归因到该用户。
- 初始认证探测失败不得在用户尚未操作时用全局错误打扰本地算表。

### RR-REPLAY-001：真实任务回放

- 未登录和已登录用户都可主动选择回放。
- 回放只在当前输入签名精确匹配已录制任务时播放。
- UI 必须显示 Task ID、录制时间、录制计算口径和当前兼容状态。
- 历史供应商正文与当前确定性数字不得混称。
- `replay.v2` 只表示审计包装，不自动意味着使用当前 Prompt。

### RR-LIVE-001：登录用户实时报告

- 已登录用户可选择平台默认、DeepSeek V4 Flash 或 DeepSeek V4 Pro。
- 请求必须显式使用 Agent/Act 模式，不得进入只规划不执行的模式。
- 页面显示任务进度、取消、超时和产物状态。
- 超时不得伪装成平台成功。

### RR-REPORT-001：报告新鲜度与重新分析

- 报告必须保存生成时的输入签名、模型和契约版本。
- 左侧输入或模型变化后，已完成报告进入 `completed-stale`。
- 报告顶部必须立即出现“基于最新输入生成新报告”入口。
- 不自动消耗额度；只有用户主动点击才创建新任务。
- 创建下一份报告时保留上一份成功报告。
- 新任务失败时，上一份成功报告仍可查看和下载。
- 新任务成功后才原子替换旧报告。

### RR-ARTIFACT-001：报告与证据边界

- 平台正文、Real Raise 确定性凭证和供应商原件必须分开。
- 产物状态至少区分 `verified`、`stream-fallback`、`deterministic-only`、`failed-retryable`。
- fallback 不得标成“平台完整报告”。

## 4. 数据需求

- 全国 2021–2025 历史收入、消费和 CPI。
- 2025 城镇消费结构。
- 2026H1 全国八类 CPI 观察值。
- 城市数据按城市原值、历史城市样本、全国回退分层。
- 住房始终使用用户输入；城市居住 CPI 只作宏观背景。
- 数据资产和覆盖状态以 [数据资产目录](../data/README.md) 为准。

## 5. 非目标

- 不做投资、借贷、辞职或消费指令。
- 不做实时抓取所有城市。
- 不用房价指数推导个人房租。
- 不让模型自行生成税费、支出或情景金额。
- 不恢复 BYOK。
- 不恢复 Judge 前端或后端产品路径。
- 不在本阶段新增数据库、账户中心或复杂历史记录。

## 6. 非功能需求

### 安全

- Secret、Cookie、API Key 不进入日志、URL、构建产物或文档。
- SSO state 与发起浏览器绑定且只能消费一次。
- Worker 不信任浏览器提交的计算结果和城市来源。

### 可审计

- 请求记录 calculation、prompt、context 和 input signature。
- 报告记录执行模式、归因、Task ID 和产物状态。
- 回放记录录制请求、当前匹配请求和供应商原件完整性。

### 可用性

- 360px、768px 和桌面可完成主要流程。
- 平台失败不影响本地计算。
- 长任务运行时用户能看到进度、取消和旧报告。
